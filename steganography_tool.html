◈ What is Steganography?

Steganography is the art of hiding secret information inside an ordinary file — in this case, a PNG image — so that no one suspects a message exists. Unlike encryption, which makes data unreadable, steganography makes it invisible.

◈ LSB (Least Significant Bit) Technique

Each pixel in an image is made of Red, Green, and Blue channels (each 0–255). This tool modifies the least significant bit of each channel to encode message bits. Changing the last bit shifts the color value by at most 1 — invisible to the human eye.

◈ Password Security

When a password is provided, the message is XOR-encrypted with the password before encoding. This adds a second layer of security — even if someone tries to extract bits, they still need the password to read the message.

◈ Capacity & Limitations

Each pixel can store 3 bits (1 per channel). A 100×100 image has 10,000 pixels = 30,000 bits = ~3,700 characters. Use PNG or BMP — JPEG compression destroys the hidden data. Always use lossless formats.
